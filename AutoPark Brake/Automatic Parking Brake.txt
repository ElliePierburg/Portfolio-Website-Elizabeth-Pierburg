Project Overview
The Problem
Yamaha is currently using manual brakes and parking brakes while competitors are using electric parking brakes.
What constraints did the project have?
The new parking brake had to keep the vehicle at budget which meant any additional cost had to be removed elsewhere. Time was constrained for initial research to POC only had 3 months. And of course, this was safety critical so must be safe.

The Solution
I developed and tested a proof-of-concept automatic parking brake system capable of electronically actuating the vehicle's brake calipers.
The system used an Arduino-based control system, motor-control hardware, sensors, and custom mechanical/electrical components to determine when the parking brake should actuate and command the brake mechanism accordingly.
